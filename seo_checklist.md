# SEO Checklist - Content Optimization

## Pre-publishing SEO Checklist

Użyj tej checklisty dla każdego materiału przed publikacją.

---

## 📋 1. Keyword Research

- [ ] **Główne słowo kluczowe zidentyfikowane**
  - Miesięczne wyszukiwania: ___
  - Difficulty: ___
  - Search intent: [Informational / Transactional / Navigational]

- [ ] **Secondary keywords (3-5)**
  - _______________
  - _______________
  - _______________

- [ ] **LSI keywords włączone naturalnie**
  - Zidentyfikowane przez: [Google autocomplete / People Also Ask / Related searches]

- [ ] **Analiza konkurencji top 3 wykonana**
  - Długość ich treści: ___
  - Unikalne punkty: ___
  - Luki do wypełnienia: ___

---

## 📄 2. On-Page SEO

### Title Tag
- [ ] **Główne słowo kluczowe w title**
  - Pozycja: [początek / środek]
  - Długość: 50-60 znaków (___/60)

- [ ] **Title jest clickable**
  - Zawiera benefit lub intrygę
  - Nie jest keyword stuffing

### Meta Description
- [ ] **Meta description napisany**
  - Długość: 150-160 znaków (___/160)
  - Zawiera główne słowo
  - Zawiera CTA
  - Jest unikalny (nie duplikat)

### URL
- [ ] **URL slug zoptymalizowany**
  - Zawiera główne słowo
  - Jest krótki (3-5 słów max)
  - Bez stop words
  - Format: /slug-z-myslnikami/

### Nagłówki (Headers)
- [ ] **H1 (jeden na stronie)**
  - Zawiera główne słowo kluczowe
  - Długość: 20-70 znaków
  - Jest inny niż title tag

- [ ] **H2 (3-7 nagłówków)**
  - Zawierają secondary keywords
  - Tworzą logiczną strukturę
  - Są opisowe, nie clickbait

- [ ] **H3/H4 (jeśli potrzebne)**
  - Używane do dalszej strukturyzacji
  - Nie nadużywane

---

## 📝 3. Content Quality

### Długość i głębia
- [ ] **Długość odpowiednia do tematyki**
  - Informational: 1500-2500 słów
  - Transactional: 800-1500 słów
  - Dłuższa niż średnia top 3 konkurentów

- [ ] **Pokrywa temat kompleksowo**
  - Odpowiada na wszystkie pytania z "People Also Ask"
  - Pokrywa subtopics z top 3
  - Dodaje unikalną wartość

### Search Intent
- [ ] **Treść odpowiada na search intent**
  - Format: [Guide / List / Review / Comparison / Tutorial]
  - Typ: [Informational / Commercial / Transactional]

### Readability
- [ ] **Flesch Reading Ease: 60-70**
  - Sprawdzone w: [narzędzie]
  - Score: ___

- [ ] **Akapity krótkie (3-4 zdania)**
- [ ] **Zdania krótkie (średnio 15-20 słów)**
- [ ] **Używa list punktowanych**
- [ ] **Używa pogrubień dla kluczowych fraz**

### Unikatowość
- [ ] **Content 100% unikalny**
  - Sprawdzony w: [narzędzie]
  - Plagiarism score: ___%

---

## 🔗 4. Internal & External Links

### Internal Links
- [ ] **3-5 linków wewnętrznych dodanych**
  - Do related content
  - Z opisowym anchor text
  - Do stron wyżej/niżej w lejku

- [ ] **Linki są kontekstowe**
  - Naturalnie wplecione w treść
  - Dodają wartość dla czytelnika

### External Links
- [ ] **2-4 linki zewnętrzne do autorytetów**
  - Do źródeł danych/statystyk
  - Do definicji/badań
  - Wszystkie działają (sprawdzone)

- [ ] **Linki otwierają się w nowej karcie** (dla zewnętrznych)

- [ ] **Używany rel="nofollow"** (gdzie potrzebny)
  - Dla linków afiliacyjnych
  - Dla user-generated content
  - Dla linków niezaufanych

---

## 🖼️ 5. Images & Media

### Optymalizacja obrazów
- [ ] **Każdy obraz ma alt text**
  - Opisowy i naturalny
  - Zawiera keyword (gdzie pasuje)
  - Format: opis-co-widac-na-obrazie

- [ ] **Nazwy plików zoptymalizowane**
  - Format: keyword-opis.jpg
  - Nie: IMG_1234.jpg

- [ ] **Obrazy skompresowane**
  - JPG/PNG: < 200KB
  - WebP preferowany
  - Używaj lazy loading

### Dodatkowe media
- [ ] **Featured image dodany**
  - Rozmiar: 1200x628px (dla social)
  - Zawiera branding/tekst overlay

- [ ] **Schemat dodany (jeśli wideo)**
  - VideoObject schema

---

## 🏷️ 6. Schema Markup

- [ ] **Odpowiedni schema type dodany**
  - Article / BlogPosting
  - Product / Service
  - FAQPage
  - HowTo
  - Review

- [ ] **Schema zawiera wszystkie wymagane pola**
  - Sprawdzone w: Google Rich Results Test
  - Errors: 0

---

## 🎯 7. User Experience

### CTA (Call to Action)
- [ ] **Główne CTA widoczne**
  - W pierwszej sekcji (above the fold)
  - Na końcu artykułu
  - W 1-2 miejscach w środku (dla długich treści)

- [ ] **CTA jest jasne i konkretne**
  - Nie: "Kliknij tutaj"
  - Tak: "Pobierz darmowy checklist SEO"

### Navigation
- [ ] **Table of Contents dodany** (dla treści 1500+ słów)
  - Linkuje do H2
  - Klikalne anchor links

- [ ] **Breadcrumbs dodane**
  - Pokazują hierarchię
  - Zawierają schema

### Mobile
- [ ] **Treść zoptymalizowana mobile**
  - Sprawdzone w Mobile-Friendly Test
  - Font size 16px minimum
  - Touch targets > 48x48px

---

## 🚀 8. Technical SEO

### Page Speed
- [ ] **Core Web Vitals w normie**
  - LCP < 2.5s
  - FID < 100ms
  - CLS < 0.1
  - Sprawdzone w: PageSpeed Insights

### Crawlability
- [ ] **Strona nie ma noindex**
- [ ] **Robots.txt nie blokuje**
- [ ] **Canonical tag poprawny**
  - Self-referencing lub do wersji kanonicznej

### HTTPS
- [ ] **Strona na HTTPS**
- [ ] **Brak mixed content warnings**

---

## 📱 9. Social Media Optimization

### Open Graph
- [ ] **OG tags dodane**
  ```html
  og:title
  og:description (120-150 znaków)
  og:image (1200x628px)
  og:url
  og:type
  ```

### Twitter Cards
- [ ] **Twitter Card tags dodane**
  ```html
  twitter:card (summary_large_image)
  twitter:title
  twitter:description
  twitter:image
  ```

---

## ✅ 10. Final Checks

### Content Review
- [ ] **Sprawdzenie pisowni i gramatyki**
  - Grammarly / LanguageTool
  - Errors: 0

- [ ] **Fakty zweryfikowane**
  - Wszystkie statystyki mają źródła
  - Daty są aktualne
  - Linki działają

### SEO Tools Check
- [ ] **Sprawdzony w Yoast/RankMath**
  - SEO Score > 80/100
  - Readability > 60/100

- [ ] **Sprawdzony w Screaming Frog** (dla ważnych stron)
  - Brak duplikatów title/meta
  - Wszystkie linki działają

### Publishing
- [ ] **Data publikacji ustawiona**
- [ ] **Kategoria/tagi przypisane**
- [ ] **Autor przypisany**

---

## 📊 Post-Publishing Tasks

### Monitoring (pierwsze 7 dni)
- [ ] **Sprawdź indexowanie**
  - site:twoj-url.com/nowy-artykul
  - Request indexing w GSC

- [ ] **Monitoruj pozycje**
  - Główne słowo kluczowe
  - Top 3 secondary keywords

- [ ] **Sprawdź User Metrics**
  - Avg. Time on Page
  - Bounce Rate
  - Scroll depth

### Promotion
- [ ] **Social media posts**
  - LinkedIn
  - Twitter
  - Facebook Groups (jeśli relevantne)

- [ ] **Newsletter mention** (jeśli pasuje)

- [ ] **Internal linking z nowych artykułów**
  - Dodaj link z 2-3 related posts

---

## 🎯 Advanced Optimizations (opcjonalne)

### Rich Snippets
- [ ] **FAQ schema dodane**
  - Minimum 3 pytania
  - Maksimum 10 pytań

- [ ] **HowTo schema** (dla tutoriali)
  - Każdy krok opisany
  - Obrazy dla kroków

### Featured Snippets
- [ ] **Optymalizacja pod featured snippet**
  - Identyfikacja możliwości (pozycja 2-5)
  - Format: Paragraph / List / Table
  - Bezpośrednia odpowiedź w 40-60 słów

### Video
- [ ] **Video dodane** (jeśli pasuje)
  - Własne lub embedded YouTube
  - Video schema dodane
  - Transcript dodany

## Narzędzia pomocnicze

### Must-have:
- Google Search Console
- Google Analytics 4
- PageSpeed Insights
- Mobile-Friendly Test
- Rich Results Test

### Recommended:
- Screaming Frog (technical audits)
- Ahrefs/Semrush (keywords & backlinks)
- Grammarly (content quality)
- TinyPNG (image compression)
- Schema Markup Generator

### Useful:
- AnswerThePublic (questions)
- AlsoAsked (related questions)
- Hemingway Editor (readability)
- GTmetrix (performance)

**Pamiętaj:** Ta checklista to minimum. Nie każdy punkt będzie odpowiedni dla każdej treści. Używaj rozsądku i dostosuj do kontekstu.
